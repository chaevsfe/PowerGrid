# Create Fly: Power Grid

Physics-based electricity for Create: wires, generators, transformers, meters, circuit boards and powered tools.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> patryk3211. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.1`, `26.1.1` or `26.1.2` |
| Mod loader | Fabric Loader `0.19.3` or newer |
| Create Fly | `6.0.9-4` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Download

- [Modrinth](https://modrinth.com/project/aCYmmLAn)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create-fly-power-grid)
- [GitHub releases](https://github.com/chaevsfe/PowerGrid/releases)


## Building

```
git clone https://github.com/chaevsfe/PowerGrid
cd PowerGrid
./gradlew build
```

Requires JDK 25.
